```bash

```

## Severity levels

| Level | Definition | Page on-call |
| --- | --- | --- |
| SEV1 | Full outage | Immediately |
| SEV2 | Degraded for some customers | Within 15 min |
| SEV3 | Cosmetic or internal-only | Next business day |

## First response

<Steps>
  <Step title="Acknowledge">
    Claim the alert so the rotation knows it is being handled.
  </Step>
  <Step title="Assess blast radius">
    Check the dashboard before changing anything.
  </Step>
  <Step title="Communicate">
    Post to the incident channel, then update the status page.
  </Step>
</Steps>
